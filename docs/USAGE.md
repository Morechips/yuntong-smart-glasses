# 使用说明与排障

## 不接设备

```powershell
.\.venv\Scripts\python.exe scripts/offline_demo.py
```

读取包内 32 张开发 JPEG，调用真实 PC ONNX 模型，每张图独立计算候选，生成 `outputs/offline_demo/preview.jpg`、单图预测及 `report.json`。摘要记录模型哈希、数量和计算时间；离线时间不代表 X5 或曝光到声振延迟，单图输出也不代表时序确认通过。

## 实机启动

1. ESP、X5 按既有接线正常供电，电脑连接现有网络。确认镜头能看到地面，没有被外壳遮挡。
2. 按安装说明填写 `config/device.local.json`，双击 `启动演示.cmd`。
3. 提交版默认关闭语音和触觉，窗口打开时不采集、不推理、不发声振。选择 X5 BPU 或 PC ONNX，点击“开始持续闭环”；X5 模式首次需要输入 SSH 密码。
4. 加载及固定图核对完成后观察实时画面。开发演示可先把相机近水平略向下，中央放白箱且两侧能看见地面。熟悉场景并有人陪同时确认放入 / 移走的输出。
5. 需要声振时先停止，再勾选相应选项。原开发反馈中音量 55 已获清晰度确认；可选 25 / 40 / 55 / 70。触觉可选 100 / 300 / 500ms，原 500ms 两路已获触感确认，但佩戴左右仍需实际核对。
6. 点击“停止”或关闭窗口。持续模式不会自动结束；已开始的一句播完、已发短振由 ESP 本地关闭，停止后不再发下一条。

## 看懂输出

| 输出 | 含义 |
|---|---|
| 青色区域 | 模型预测地面 |
| 红 / 橙候选 | 主要 / 其他非地面缺口候选，未必对应完整物体 |
| 紫色关注区 | 地面通道估计；不是安全通道认证 |
| 灰色关注区 | 通道估计不足，使用固定区域降级 |
| `PENDING` | 等待后续不同帧确认 |
| `OBSTACLE LEFT/CENTER/RIGHT` | 障碍候选在图像内的左 / 中 / 右区域 |
| `NO_CANDIDATE` | 本次未检出候选，不能理解成通行安全 |
| `UNKNOWN` | 地面不足、输入失效或结果过期等，无法给出有效结论 |

主入口的马达含义仍是障碍所在方向：左 → left，前 → both，右 → right。盲道候选里的马达含义是图像偏位纠偏，不能混用两种入口。

## 时效、反馈与日志

仅处理最新帧和最新反馈状态。结果有效期从电脑完整 JPEG 接收起算 0.5 秒；未完成源时钟映射，不能据此保证曝光时刻新鲜。断流清除旧候选，持续模式按原地址退避重连；若 ESP 重启换 IP，应停止后重新配置 / 发现。

同方向语音最多约每 6 秒开始一句，变化也至少间隔 2 秒；触觉间隔至少 1.5 秒。输出串行，不会抢占已经开始的语音。请求失败后停用该反馈，停止重开前不会重试可能已执行的旧指令。

记录写在 `benchmarks/ground_demo_20261101/runs/live_*/`，已被 Git 忽略。单次事件日志约 4×8MiB、持续截图最多 12 组、耗时统计最多最近 2048 结果；旧运行目录需用户自行管理。运行记录可能带现场图像，不默认提交。

## 常见问题

| 现象 | 处理 |
|---|---|
| 找不到 Python / 包 | 用仓库 `.venv` 按 `SETUP.md` 安装，不复制原电脑虚拟环境 |
| SSH 指纹未配置 / 不匹配 | 在可信设备端核对实际密钥指纹并填写本地配置；不要跳过验证 |
| 找不到唯一 ESP | 核对上电、实际 MAC 和热点；直连路径填当前 `esp_url` |
| 有画面但全 UNKNOWN | 确认相机朝向和地面可见；不靠放宽有效期延续旧提示 |
| X5 启动固定图不一致 | 停止，核对模型哈希、运行库与输入合同；不能当作已部署成功 |
| 声音小或马达没感觉 | 先确认固件能力、窗口开关及实际接线，再有界试听 / 短振；回执不等于已实际感知 |
| 秒级卡顿 / 图传超时 | 已有未解决记录，见 `STATUS.md`；停止并保留日志，不能只看平均帧率判稳定 |
| X5 文件 I/O 错误 | 停止运行并排查系统 / 存储；本包不自动修复、重启或刷卡 |

本版是实验辅助原型，保留漏检、合框与方向粗糙等限制；试装不能替代独立助行工具或现场照护。
