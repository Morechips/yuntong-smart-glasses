# 项目提交说明

## 作品与提交范围

作品名称：云瞳助行——基于视觉感知与声振交互的智能助盲眼镜工程原型。

本包是 2026-11-04 的代码与结构设计快照，用于 GitHub 项目提交。包含当前可演示的地面障碍提示链路、双模型（地面＋盲道）联调入口、对应模型和必要开发样本、ESP32-S3 固件源码、头戴与随身计算盒建模，以及安装、使用和装配说明。提交包本身不包含签字盖章申报表、团队联系方式或个人证明材料。

## 模块分工

| 模块 | 当前职责 | 工程入口 |
|---|---|---|
| ESP32-S3 / OV3660 | 采集 JPEG、HTTP 图流、外设接口 | `firmware/esp32s3/main/` |
| JY61P IMU | 独立姿态采样 / 同步协议 | `glasses_imu_stream.*`、`glasses_sync_core.*` |
| RDK X5 | 加载并运行已量化的地面 BIN | `benchmarks/ground_demo_20261101/board_worker.py` |
| 电脑 | 图流中继、后处理、状态确认、界面与反馈调度 | `live_demo.py`、`corridor_decision.py`、`joint_app.py` |
| 语音 / 双振动模块 | 已确认障碍的方位提示 | `speech_output.py`、`glasses_peripheral_bench.c` |
| 结构件 | 固定主板、相机、IMU、外设与计算端 | `3D打印文件/` |

IMU 采样不等于已完成视觉姿态融合。当前地面提示不估距离、不做空间占用地图或完整导航。双模型联调入口已并入本包，其盲道分支的佩戴左右与身体航向仍待验证。

## 实现要点

1. 同一份开发模型经 ONNX 与 X5 BIN 两条后端运行；X5 启动时用固定开发图核对量化模拟类别输出。
2. 从预测地面的内部非地面缺口提取候选，保留两帧确认、结果过期清除、断流重连与来源代次检查。
3. 通道优先模式估计图像地面中轴，支持多个确认区域；条件不足时降级固定区域。该几何区域尚不是已标定的人体净空。
4. 声音和马达请求串行处理最新状态，采用提示间隔及本地有界脉冲，失败后停用相应反馈。
5. 结构保留可编辑 STEP、单件 STL、切片 3MF 和真实 CAD 渲染图；不同版本按模块组合使用。生成这些模型的脚本和参数文件仅保留在原工程中，不随本提交包附带。
6. 双模型入口在同一进程内顺序运行地面与盲道两个模型，共享图流与调度；障碍出现时优先语音并抑制纠偏振动。
