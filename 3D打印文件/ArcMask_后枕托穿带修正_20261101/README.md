## 打完怎么清理

1. 冷却后取件，先去外裙边。
2. 将底部生成支撑分小块剪开清理，靠近连接处时用钳口接近界面，避免整片撬动薄弧面或以安装柱作杠杆。
3. 清空左右带槽和中间顶带槽，保留槽框。**两根电池安装柱、上下宽连接根和全部槽框都是本体**，见辨认图。
4. 先穿自由带尾并回折，再装原电池盒；孔位未改。先小幅试拉观察连接根/柱根，再试装带软垫。实际织带缝边、硬扣、折弯和粘合长度仍需实配，不强塞。

用户实物显示后枕托长带口紧靠电池安装柱，带子穿出后无法转弯。源码确认原槽内侧X44.5与柱外缘X44.2只有0.3mm；之前孔贯通检查遗漏穿出、转弯和回折路径。这是设计遗漏，不要求靠硬塞或剪安装柱解决。此前“旧佩戴件继续复用”的建议须撤回后枕托这一项。

两个耳各向外8mm，上下连接梁各3.75mm高、沿Y为12mm深，连到原弧面后按原软垫包络裁切；四根部均有正体积重叠。梁位于织带上下，不穿过进带通道。电池盒、前部壳体、B分体内架和旧文件不改。

自由带尾从外侧沿X穿过长槽，从槽内侧出来后在柱外侧的新空区向前转弯，围过带耳前侧横条，向原侧带方向回折粘合。左右镜像。橙色为织带占用空间，不是打印件。按25mm宽、单层最大2.5mm、中心线转弯半径3.5mm建立；半径是检查候选，不是已验证的织带弯折要求。6mm净槽不表示硬扣、缝边或整个闭合环均能穿过。

## 检查边界

29项数字检查包括：原几何重建对已交付STEP，新件单实体/有效、STEP往返、STL闭合与候选落床，左右完整U形包络及连续直线穿入通道对枕托/原电池盒的避让，原孔/工具通路、主接触壳与软垫包络保留、四根部实体重叠、旧源SHA不变。

**绑带已到，最厚缝边/魔术贴单层厚度尚未实测反馈。** 之前1.6mm及本轮2.5mm均为设计假设，已单独询问这一项，不需要重测其他元件。实际带宽、缝边/硬扣通过、折弯和粘合长度、支撑拆除/强度、软垫及佩戴均待验；`all_checks_passed=false`。

此前“暂不发布带G-code的3MF、等待厚度”的停点由本轮用户要求继续建及上述单件工程取代；实测待验并未关闭。仅该后枕托一件补打，原件不建议剪柱或削薄承力根部。不涉及打印提交或电子设备操作。
