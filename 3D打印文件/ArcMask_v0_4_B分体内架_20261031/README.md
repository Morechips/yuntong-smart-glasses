## 切片结果

当前本机Bambu Studio 02.08.02.61，A1/0.4mm、Generic PETG、纹理PEI、层高0.2、4墙、20%陀螺、喷嘴255°C/热床80°C，最大体积流量沿用8mm³/s。耗材温度仍应匹配实验室实际PETG。

最终G-code预测 **2:14:08，24.34g**，含支撑和brim；不是实称或保证用时。六件按层一起打印，不逐件打印。03/04启用局部普通贴合支撑，允许支撑从模型底板上生长；其余四件关闭支撑。G-code仅03/04有支撑挤出，不把“全盘开支撑”作为默认。

保留现有摆向：共同骨架和主板托架大平面贴床、柱朝上；相机盖正面贴床，上耳向上。不要全选自动摆向、整体缩放或把所有支撑关掉。切片器若因用户材料/预设版本重新计算，用时可能变化。

## 正式化时与概念B的区别

- 新增14套M2螺丝/螺母的实体包络、螺母承力台和可取出开口；M2头部按Ø5×高3的保守候选空间检查，非声称用户所有头型都已量过。
- 主板PCB正面布局基准从概念Y10移至Y12，保持孔距和外壳接口，缩短托架锁板螺丝到M2×12；正面6.1、板1.6、背面3.1分层保留。
- 相机压盖改成**上侧两颗M2×8**，避免正面螺丝头侵入旧平前盖。侧窗先装螺母，靠硬台限制压盖行程。方腔名义8.6，容纳8mm底座；托底至盖后面约2.3，给约2.2底座保留约0.1薄定位层。实际底座厚度为约数，不能强压到位。
- IMU未装排针侧使用连续防脱条，硬限位使条后面与名义PCB正面约留0.2；底托预留约0.1薄定位层。它不靠压金属罩固定，不再按未确认的焊盘间距制造接触小齿。若有晃动，薄层定位后再检查；不塞厚泡棉悬挂IMU。
- 两处理线座为开放4.2mm槽，可侧放原线并用细扎带/线绳止拉，不要求把旧插头剪掉。不能认为一个槽已验证能塞下全部24AWG线束。

## 数字检查与剩余限制

[65项实体/装配检查](qa/validation.json)通过：六件有效单实体、正体积；彼此/简化元器件及IMU针脚预留、旧外圈及前后盖无检查阈值以上穿入；14组螺丝、螺母、头部和候选直线工具空间；三个小座前向装入的离散位置；STEP往返和STL封闭/绕向一致。原四份生产源哈希保持不变。

[最终3MF/G-code核验](qa/project_verification.json)通过：六件源STL对应、无缩放/漏切/越床、单盘摆位、各对象设置与实际支撑挤出范围。只保留传统延时摄影兼容提示，未连接打印机、未发送打印。

**仍未验：** 真实元件/焊点与插头细节、实际螺丝/螺母尺寸、相机/IMU最终接触及薄定位层、FPC整条路线和光学视场、原线长度/弯曲/止拉、PETG清支撑/承载/热与佩戴。`all_checks_passed=false`有意保留。紫色走线图仅说明安装方向，不能据图裁线；FPC仍按60mm保守预算、待原线实摆。

开发期发现过压盖上耳与相机底托重叠，以及共同骨架一个相切圆柱导致非流形STL，均已在源几何中修正并重建，不通过网格修补或缩放掩盖；旧模型/旧3MF原样保留。
