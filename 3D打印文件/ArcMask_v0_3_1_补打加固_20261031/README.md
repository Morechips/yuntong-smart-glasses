## 怎么改的

1. **窗边两柱**：改成8mm宽、6.8mm高的连续螺母承台，接到未挖沉台的完整顶壁；不再仅依赖0.2mm薄连接边。承台与内架保留0.4mm名义退让。检修开口仍26×14，支座螺丝孔距32→36，所以配套小盖改为45.6×19.6；旧37.6宽小盖不能混用。这里仍有螺母孔，不是取消固定功能。
2. **四斜脚**：从曲面架上取消，拆成左右两张3mm平板连接片，背面仅有2.5mm高的短方垫台；不再打印长细圆杆和小圆耳。原外圈四接口X±73/Z±26/Y40、后头座Y43不变。
3. **薄曲面**：脸框1.6→3.0、额托2.2→3.0；向非贴肤侧加料，原软垫接触曲率和位置保持。额/脸之间两根Ø4圆桥筋换成10mm宽连接肋，额托通风孔缩为两个较小孔、顶带锚点加宽。鼻部开口保留，不用硬横杆跨鼻梁。

原壳体含耳外廓178.4×70、含安装柱深40不增加；相机、主板、弯针IMU、原电池/两个完整振动模块及2209喇叭不换，不要求重接全部线束。加固增加塑料和4套连接紧固件，不宣称减重或已证明足够强。

## 新增紧固件与装配

新增连接片到架体共4颗M2螺丝、4颗M2螺母；M2×10是名义试配候选，垫片/实际头型与螺钉尖端余量要实物核对。原外圈四颗连接螺丝和小盖两套螺丝/螺母可先试用原件，不能沿用过长螺钉硬顶。

**先把左右连接片安装到曲面架，再将整个佩戴模块装到外圈。** 内侧一列孔用于新架体，外侧一列孔才对应原四个外圈孔；螺丝装入方向不同，见[装配说明](ASSEMBLY.md)。
