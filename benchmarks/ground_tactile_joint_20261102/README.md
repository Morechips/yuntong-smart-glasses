## 候选行为

1. 原地面BIN、原工作进程和通道决策只读复用。独立盲道进程用原GuideTWSI YOLO11n-seg 640 NV12 BIN，SHA256 `4c5150ce17c1e09264ffbadc20a0af84733be8c5edfbc579aded69f4f47b7439`；复用历史NumPy softmax兼容解码器，不安装依赖或重新量化。
2. 一路ESP图流，两模型当前顺序调用：先发布避障状态，再低频约3Hz运行盲道。模型各自常驻；盲道当前任务不能抢占，不承诺共跑无额外延迟。调用超过200ms会停用盲道分支并记录，不能用这个实验预算替代最终120ms时延门。
3. 每份结果绑定原始接收时间、设备boot／stream和连接代次。右侧盲道截图显示其自己的源帧，不把旧掩膜贴在新的原图上。结果有效期0.5秒，换源／断流清空。
4. 近端只有一个有纵向支持的盲道连通域时才估画面偏位；连续3个不同观察同向确认，进入阈值0.16／退出0.10（归一化图像偏位，非米）。缺少近端支持／多条候选歧义为UNKNOWN，不把提示点当转弯或盲道终点判断。
5. 画面盲道偏左→候选左马达提示朝左修正，偏右→右，居中→不振；**含义是图像内纠偏，不是已标定的身体航向／安全转向**。需镜头固定朝前、佩戴左右确认；现在两项都未现场验证。任何障碍、PENDING、地面UNKNOWN／过期都抑制盲道震动，不能靠盲道掩膜删掉障碍。
6. 障碍语音复用原七句／55，马达不再承担障碍方向；声振共用输出锁、最新单槽，能力查询后语音仍复核时效；500ms单脉冲／间隔至少1.5秒，失败停用、不重发。固件不能中断当前语音，所以语音播放期间暂不能发纠偏脉冲，不能称真正抢占。
